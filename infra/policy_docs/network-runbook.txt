  - refdata-app (10.60.7.0/24) has no 0.0.0.0/0 -> IGW; vendor calls cannot
    go direct.
  - all outbound vendor traffic egresses via the shared host in
    bank-demo-proxy (forward proxy, tcp/3128). the host is a standing EC2
    instance in that subnet; its address is assigned by the subnet.
